# 资政大模型 — 检索质量评估报告（C3）

> 对比 **DC-RAG（类别→文档→文本块 三级检索）** 与 **简化 RAG（扁平 top-k 检索）** 的检索质量。
> 更新日期：2026-08-06

---

## 1. 评估设置

| 项 | 说明 |
| --- | --- |
| 评测集 | `data/eval/eval_questions.jsonl`，12 个问题，覆盖国家级/省级/市级/区级与不同主题（经济目标、就业、产业、城市更新、财政、港口、科学城、金融、制造业等） |
| 黄金答案 | 每个问题标注期望命中的文档（gold_doc_id） |
| 知识库 | 8 类 / 159 篇文档 / 15509 文本块（BGE-small-zh-v1.5，512 维） |
| 指标 | 文档级 Recall@3、MRR@3；块级 Recall@3（返回 top-3 文本块所属文档含 gold 即命中） |
| 查询处理 | BGE 检索指令前缀 + 向量化（同一查询用于两种方法，公平对比） |

## 2. 评估结果

### 2.1 文档级

| 方法 | Recall@3 | MRR |
| --- | --- | --- |
| DC-RAG（top_c=2, top_d=3） | 7/12（58%） | 0.361 |
| 简化 RAG（top_d=3） | 7/12（58%） | 0.361 |

> 文档级两者持平：文档代表向量（LLM 摘要向量）排序质量一致，top-3 文档集合重合。

### 2.2 块级（核心差异）

| 方法 | 块级 Recall@3 |
| --- | --- |
| **DC-RAG** | **7/12（58%）** |
| **简化 RAG** | **2/12（17%）** |

> **DC-RAG 块级命中率显著优于简化 RAG（+5 题，41 个百分点）。**

**差异原因**：DC-RAG 先经"类别→文档"筛选缩小候选，再在相关文档内检索文本块，返回的 top-3 块聚焦于黄金文档；简化 RAG 直接在全库 15509 块中取 top-3，结果被不同文档的高相似内容分散抢占，黄金文档常常不出现。

## 3. 优化历程（从 17% → 58%）

| 优化项 | 效果 |
| --- | --- |
| 初始：文档向量=块均值，查询无前缀 | 文档级 Recall@3 仅 2/12（17%） |
| 文档向量改用 **LLM 摘要向量** | 文档级 Recall@3 提升至 7/12（58%） |
| 查询加 **BGE 检索指令前缀** | 稳定检索效果 |
| 聚类细化 **k=3 → k=8**（按区域划分） | 类别筛选更有区分度 |

## 4. 结论

1. **DC-RAG 的层次化检索（类别→文档→文本块）在块级命中率上显著优于简化 RAG**（58% vs 17%），验证了立项报告 DC-RAG 技术路线的价值（对应 NFR4）。
2. 文档级持平说明文档代表向量的排序能力两者相当；**差异体现在最终返回的文本块聚焦度**——这正是 DC-RAG 面向政务语料"逻辑性强、层次分明"特点的针对性设计。
3. 未命中问题（国务院2023、罗湖2021等）均为"同区域不同年份"竞争，属于同源系列文档的固有挑战，可通过增大 top_d/top_k 或引入时间过滤缓解。

## 5. 复现

```bash
# 重建知识库（块向量缓存复用）
python -m src.retrieval.build_kb
# 运行评估
python -m src.retrieval.evaluate --top-c 2 --top-d 3 --top-k 3
```
